Decisions made here:
- Bus name `presto` (identity "Presto") real, `presto-demo` (identity "Presto (Demo)") demo, so a demo run never adds a second `presto` player (research demo isolation). `desktop_entry = "presto"`, `uri_schemes` empty.
- Task loop wakes on: `state_rx.changed()`, a `Notify` set by the crate's wake closure, and a 1 s interval. Each wake: drain `np.commands()`, then `np.update(...)`.
- First `update` with an all-false `State` is sent immediately after `NowPlaying::start` so CanSeek/CanPlay are correct before any track (research open question 2).
- After a Seek is applied call `np.seeked(Duration::from_millis(ms))`.
- If `NowPlaying` is not `Send` inside `rt.spawn`, run the loop on a dedicated `std::thread` using `Handle::block_on` for the waits; keep ownership in one place.
- MPRIS failure is never fatal: no session bus logs a warning inside the crate and the app continues.
- Engine MediaSession stays disabled (D-12): add a guard test, do not touch `engine/main.js` flags.

`start` body: `let wake = Arc::new(Notify::new()); let w = wake.clone(); let mut np = NowPlaying::start(app, move || w.notify_one());` first `np.update(State::default() with Controls all false)`. Then the loop (on `backend.spawn`, or a std thread per the decision above):

```rust
let mut rx = backend.state(); let pos = Position::new(); let mut tick = interval(1s);
loop {
  select! { r = rx.changed() => if r.is_err() { break }, _ = wake.notified() => {}, _ = tick.tick() => {} }
  let s = rx.borrow().clone();
  for c in np.commands() {
     if let Some(op) = command_op(&c, &s) { if let Ok(acts) = plan(&op, &s, pos.now(&s)) {
         if matches!(op, CtlOp::Seek{..}|CtlOp::SeekBy{..}) { /* compute target from the planned Cmd(Seek{ms}) and call np.seeked */ }
         apply(&*ctl, acts) } }
  }
  np.update(mpris_state(&s, pos.now(&s), art_for(&s, &*ctl)));
}
```
Art `Pending` yields `None`, and the 1 s tick re-evaluates it so the file appears once cached (D-10; never set `art_url`). Do not publish volume from any path that also sends a command (Pitfall 8).
