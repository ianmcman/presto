Decisions made here:
- Paths: real `$XDG_RUNTIME_DIR/presto/ctl.sock` + `ctl.lock`; demo `ctl-demo.sock` + `ctl-demo.lock`. Dir via `presto_core::paths::ensure_private_dir`.
- Single instance = `nix::fcntl::Flock` LockExclusiveNonblock on `ctl.lock`, held for process life; the holder unlinks and rebinds the socket, chmod 0600. No `fastframe-instance`.
- Request-reply ops are acknowledged when accepted (`Control::send` is fire and forget); rejections reply `ok:false` and exit code 3.
- Limits: request line at most `MAX_LINE` (4096) bytes, 10 s idle read timeout on request-reply connections, subscribe ends when the peer closes or a write fails.
- Subscribe emits the current status first, then a line when `status_json` changes; position-only changes at most once per second; a 1 s tick advances position while playing.
- Client is plain `std::os::unix::net::UnixStream`, no tokio. `ConnectionRefused` and `NotFound` mean not running.
- `XDG_RUNTIME_DIR` unset: print `XDG_RUNTIME_DIR is not set` and exit 2 for both CLI and GUI paths.

`run` maps: `Sub::to_op` error -> stderr message, return 2; `NotRunning` -> stderr `presto is not running`, return 1 (D-02, no auto-launch); reply `ok:false` -> stderr the error, return 3; `Status{json:false,watch:false}` prints `status::one_line`; `Status{json:true,watch:false}` prints `serde_json::to_string(&status)`; `watch` keeps reading lines until EOF, printing the same way per line and flushing stdout each line (waybar); everything else prints nothing and returns 0. Set no read timeout on the watch stream.

`main.rs` new order (Pitfall/startup order from research):
1. `Cli::parse()`. Read `XDG_RUNTIME_DIR` (exit 2 with message if unset); `let p = CtlPaths::new(&rt, cli.demo)`.
2. If `cli.cmd` is Some: `exit(client::run(&p, sub))`. No Backend, no eframe.
3. GUI: `let guard = match ctl::lock(&p) { Ok(g) => g, Err(Held) => exit(match client::request(&p, CtlOp::Raise) { Ok(r) if r.ok => 0, _ => 1 }) (D-03), Err(e) => eprintln + exit 1 }`. This runs before `Backend::start` so the engine profile lock is never contended.
4. Existing cfg and `Backend::start`. In the eframe creator closure, before `App::new` moves the backend: `let ctl = backend.control(cc.egui_ctx.clone()); let listener = { let _g = backend.enter(); guard.bind() }; backend.spawn(ctl::server::serve(listener, backend.state(), ctl));` A bind failure prints a warning and continues (the app still works without the CLI).
5. Keep `guard` in `main`'s scope so it drops after `run_native` returns (removes ctl.sock). `on_exit` and `App` are unchanged (D-05).
