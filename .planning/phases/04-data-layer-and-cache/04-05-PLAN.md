  <action>
Implement data/artwork.rs per the contract in this plan's interfaces block.

- `expand`: snap `px` to the smallest `ART_SIZES` entry >= px, else 640; replace `{w}` and `{h}` with it. One cached file then serves many views.
- `file_for`: hex of `sha2::Sha256::digest(url.as_bytes())` (format bytes with `{:02x}`), path `dir/hex[..2]/hex`. Not `DefaultHasher` (unstable across toolchains).
- `open`: create `dir` with `paths::ensure_private_dir`; walk the two-level tree, delete files ending `.part`, sum the rest into `total`.
- `fetch(url)`: `self.http.get(url).send().await`, `error_for_status()`, `bytes()`; map reqwest errors to `io::Error::other`. Create the shard dir, write to `<final>.part`, `rename` to final, then `total += len` and `evict()` if `total > cap`. Run file IO in `tokio::task::spawn_blocking`.
- `evict()`: collect all files with `(mtime, len, path)`, sort by mtime ascending, delete until `total <= cap * 9 / 10`. `// ponytail: full directory scan per eviction; keep an in-memory index if eviction shows up in profiles.`
- `get(url)`: if `file_for(url)` exists, touch it (`File::options().write(true).open(p)?.set_modified(SystemTime::now())`, ignore errors) and return `Ready`. If `failed[url]` is younger than `FAIL_RETRY`, return `Failed`. If `url` is in `inflight`, return `Pending`. Else insert into `inflight`, `tokio::spawn` a task that runs `fetch`, removes from `inflight`, and records `failed[url] = Instant::now()` on error; return `Pending`.
- reqwest client: `reqwest::Client::builder().timeout(Duration::from_secs(20)).build()`. This client only talks to artwork CDN hosts from response JSON; never point it at api.music.apple.com (CLAUDE.md).
- `clear()`: `remove_dir_all(dir)`, recreate with `ensure_private_dir`, zero `total`, clear `failed`.

Tests: `#[tokio::test]` with a stub `tokio::net::TcpListener` on 127.0.0.1:0 that reads the request head and answers `HTTP/1.1 200 OK\r\nContent-Length: N\r\nConnection: close\r\n\r\n` + N bytes (or 404), counting hits in an `Arc<AtomicUsize>`. To make mtimes distinct in the LRU test, set them explicitly with `set_modified` (now - 30 s, now - 20 s) instead of sleeping. Poll `get()` with a short `tokio::time::sleep` loop up to 2 s for Ready.
