  <action>
Add a `probe` stdin command to examples/live.rs and list it in the doc comment.

`probe` first waits up to 90 s on `core.state()` for `engine == EngineStatus::Ready && auth == Some(AuthState::SignedIn)`; on timeout print `probe: not ready` and return. Then it runs these GETs sequentially, each printed as one line `probe <label> <result>`:
1. `sf`: `/v1/me/storefront`; take `data[0].id` as `sf` for later catalog paths (fallback `us`).
2. For each `ty` in `songs, albums, artists, playlists` and each `sort` in `none, name, -name, dateAdded, -dateAdded`: `/v1/me/library/{ty}` with `limit=5` plus `sort=<sort>` unless `none`. Label `lib-{ty}-sort={sort}`.
3. `lib-songs-limit100`: `/v1/me/library/songs?limit=100`; `lib-songs-limit101`: `limit=101`.
4. `recent-10`: `/v1/me/recent/played?limit=10`; `recent-11`: `limit=11`; `recent-off10`: `limit=10&offset=10`; `recent-tracks-30`: `/v1/me/recent/played/tracks?limit=30`.
5. `recs`: `/v1/me/recommendations?limit=10`. Take the first group's `id` as `rid`, then `recs-id`: `/v1/me/recommendations/{rid}`, `recs-contents`: `/v1/me/recommendations/{rid}/contents?limit=10`.
6. `search`: `/v1/catalog/{sf}/search` with `term=love, types=songs,albums,artists,playlists, limit=25, with=topResults`.
7. `hints`: `/v1/catalog/{sf}/search/hints` with `term=lov, limit=10`.
8. `libsearch`: `/v1/me/library/search` with `term=a, types=library-songs,library-albums,library-artists,library-playlists, limit=25`.

`<result>` for `Outcome::Err` is the error JSON. For `Ok` it is a JSON object with: `"keys"` (top-level keys of data), `"names"` (first 5 `data[*].attributes.name`, or for recs `data[*].attributes.title.stringForDisplay`), `"ids"` (first 5 `data[*].id`), `"types"` (distinct `data[*].type`), `"next"`, `"total"` (`meta.total`), `"len"` (`data` length), and `"shape"`: a copy of data where every array is cut to its first element and every string longer than 24 chars is cut to 24 chars, then the whole shape string cut to 1500 chars. For `search`, `hints` and `libsearch` put `results` keys and, per key, the data length into `"keys"`/`"len"` as `{key: len}`.

Write the helper as one `fn shape(v: &Value) -> Value` and one `fn summarize(label: &str, o: &Outcome) -> String`; no new dependencies.
