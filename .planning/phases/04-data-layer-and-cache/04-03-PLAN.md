Implement data/store.rs per the interfaces block in this plan.

`Store { conn: Arc<Mutex<rusqlite::Connection>> }`, `#[derive(Clone)]`. `open(path)`: try `init(Connection::open(path)?)`; if that fails, or `PRAGMA user_version` is greater than 1, drop the connection, remove `path`, `path-wal`, `path-shm` (ignore NotFound) and retry once. `init` runs:
```sql
PRAGMA journal_mode=WAL;
CREATE TABLE IF NOT EXISTS pages(account TEXT NOT NULL, req TEXT NOT NULL, off INTEGER NOT NULL, fetched_at INTEGER NOT NULL, body BLOB NOT NULL, PRIMARY KEY(account, req, off)) WITHOUT ROWID;
CREATE TABLE IF NOT EXISTS search_history(account TEXT NOT NULL, term TEXT NOT NULL, at INTEGER NOT NULL, PRIMARY KEY(account, term)) WITHOUT ROWID;
CREATE TABLE IF NOT EXISTS meta(k TEXT PRIMARY KEY, v TEXT NOT NULL) WITHOUT ROWID;
PRAGMA user_version = 1;
```
(Read user_version before creating tables; the cache is disposable, so no migrations: an unknown version means delete and recreate.) `open_in_memory()` uses `Connection::open_in_memory()` + `init`, panics on error (tests only, still `pub`).

SQL: get_page `SELECT fetched_at, body FROM pages WHERE account=?1 AND req=?2 AND off=?3`; put_page `INSERT OR REPLACE`; drop_pages_from `DELETE FROM pages WHERE account=?1 AND req=?2 AND off>=?3`; push_search `INSERT OR REPLACE INTO search_history VALUES(?1,?2,?3)` then `DELETE FROM search_history WHERE account=?1 AND term NOT IN (SELECT term FROM search_history WHERE account=?1 ORDER BY at DESC LIMIT 10)`; search_history `SELECT term ... WHERE account=?1 ORDER BY at DESC LIMIT 10`; wipe deletes from all three tables. Use `prepare_cached`. `now_ms()` = `SystemTime::now()` since UNIX_EPOCH in ms as i64.

Errors are logged with `eprintln!("presto-core: store: {e}")` and turned into None / no-op. Never log `body`.

Unit tests for every behavior bullet, using `tempfile::tempdir()` for the file-based ones.
