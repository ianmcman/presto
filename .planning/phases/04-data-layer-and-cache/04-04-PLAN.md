From presto-core (supervisor.rs, state.rs):
```rust
#[derive(Clone)] pub struct CoreHandle;  // fn state(&self) -> watch::Receiver<CoreState>; async fn request(&self, req: ApiRequest) -> Outcome
pub struct CoreState { pub engine: EngineStatus, pub auth: Option<AuthState>, pub restarts: u32, .. }
pub enum EngineStatus { Starting, Ready, Restarting{..}, Drift{..}, Failed{..} }
```
Note: the supervisor queues requests sent before Ready, so the client must check state itself to fail fast.
From presto-ipc: `ApiRequest::get(path)`, `query: BTreeMap<String,String>`, `Outcome::{Ok{data: Value}, Err{error: IpcError{kind, message}}}`, `AuthState::{SignedIn, SignedOut, SigningIn, Expired}`.
From 04-03 data/error.rs: `UiErrorKind { Offline, SignedOut, AuthExpired, RateLimited{retry_after_ms}, Timeout, Unavailable, Upstream{status}, NotFound, Internal }`, `UiErrorKind::from_ipc(&ErrorKind)`.
From 04-01 mock: `--storefront <id>` (catalog paths with another storefront get not_found), `--fault rate_limited=<ms>`, `--auth signed_out`, `--bridge-missing` (never Ready).
Test rig (tests/common/mod.rs): `rig(argv) -> Rig { core, calls, dir }`, `wait_for(&mut rx, within, pred)`, `mock_bin()`.

Contract this plan creates:
```rust
#[derive(Clone)]
pub struct ApiClient { /* core: CoreHandle, state: watch::Receiver<CoreState>, sem: Arc<Semaphore>, storefront: Arc<RwLock<Option<String>>>, install_id: Arc<str> */ }
pub const MAX_IN_FLIGHT: usize = 4;
pub fn catalog_req(sf: &str, rest: &str, query: &[(&str, &str)]) -> ApiRequest;
impl ApiClient {
  pub fn new(core: CoreHandle, install_id: String) -> ApiClient;
  pub fn core(&self) -> &CoreHandle;
  pub fn gate(&self) -> Result<(), UiErrorKind>;
  pub async fn get(&self, req: ApiRequest) -> Result<Value, UiErrorKind>;
  pub async fn storefront(&self) -> Result<String, UiErrorKind>;
  pub async fn refresh_storefront(&self) -> Result<String, UiErrorKind>;
  pub fn cached_storefront(&self) -> Option<String>;
  pub fn set_storefront(&self, sf: Option<String>);
  pub fn account_key(&self) -> Option<String>;   // "{storefront}:{install_id}"
  pub async fn catalog(&self, rest: &str, query: &[(&str, &str)]) -> Result<Value, UiErrorKind>;
}
```
