Verify struct becomes: `target: u64, resume: bool, started: Instant, seek_tries: u32, seek_since: Option<Instant>, state_tries: u32, state_sent: Option<Instant>, ok_since: Option<Instant>`. `begin_restore` sets `started: Instant::now()` and the rest to 0/None. Keep the initial step list in `begin_restore` unchanged (the trailing Play/Pause is harmless; verify corrects it).

Rewrite `verify_step` in this order, reading `(pos, state)` from the mirror:
1. If `started.elapsed() >= VERIFY_DEADLINE`: log `presto-core: restore: not confirmed within 20 s (at {pos} ms, want {target} ms, state {state:?})`, return Done.
2. If `state == PlayState::Loading`: set `ok_since = None`, `seek_since = None`, return Wait. Never send Play/Pause/Seek while loading.
3. `landed = pos + SEEK_TOLERANCE_MS >= target`. If not landed: `ok_since = None`; start `seek_since`; if under `SEEK_SETTLE` return Wait; if `seek_tries >= SEEK_TRIES` log the existing "not confirmed after {SEEK_TRIES} tries" line and return Done; else `seek_tries += 1`, `seek_since = None`, return `Retry([Seek { ms: target }])`. Seek only, no trailing Play/Pause.
4. `state_ok = if resume { Playing } else { Paused }`. If not state_ok: `ok_since = None`; if `state_sent` is under `STATE_SETTLE` return Wait; if `state_tries >= STATE_TRIES` log `presto-core: restore: state not confirmed after 5 tries (state {state:?})` and return Done; else `state_tries += 1`, `state_sent = Some(now)`, return `Retry([Play or Pause])`.
5. Both ok: `ok_since.get_or_insert(now)`; return Done only when it has held `VERIFY_HOLD`, else Wait. Any later bad observation resets `ok_since` (steps 2 to 4).

Logging: change `inflight` to `Option<(u64, Command)>` (clone the command when sending in `pump`). `step_result(&mut self, cmd: &Command, o: &Outcome)` derives `load = matches!(cmd, Command::SetQueue { .. })` and first logs every reply: `presto-core: restore: {cmd:?} -> {ok|err:?}, state {state:?} at {pos} ms`. Update both call sites (Tick timeout path and Frame::Res path) accordingly.
