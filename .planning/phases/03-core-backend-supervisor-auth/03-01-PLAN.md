```
{"t":"evt","evt":{"type":"bridge_ready","version":"1.1.0","capabilities":["playback","queue","api"],"musickit_build":"3.x" | null}}
{"t":"cmd","id":N,"cmd":{"type":"show_window","show":true}}

engine hello caps gain "window"; proto {"major":1,"minor":1}
```

Existing (crates/presto-ipc/src/frame.rs): `pub const PROTO: ProtoVersion = ProtoVersion { major: 1, minor: 0 };`, `pub mod caps { PLAYBACK, QUEUE, API, MOCK }`.
Existing token guard (crates/presto-ipc/tests/common/mod.rs): any `_`/`-` segment in FORBIDDEN (token, auth, authorization, bearer, jwt, secret, cookie, password, credential) fails unless the whole name is `auth` or `auth_expired`. New names `bridge_ready`, `show_window`, `show`, `play`, `version`, `capabilities`, `musickit_build` pass.

Mock (crates/presto-engine-mock/src/main.rs): startup frames are built after the hello exchange from `--fault` specs; if none produced events, it pushes `Auth{SignedIn}`. Startup frames are subject to hang gating. `Engine::handle` rejects every Cmd/Req with AuthExpired while `faults.auth_expired`. `Faults::apply(FaultSpec::None)` clears faults and emits `Auth{SignedIn}` only if it was expired.
Catalog ids: s1..s5 (crates/presto-engine-mock/src/catalog.rs).
