    2. Add `/// Post-load check that the seek landed and the play state is right (RESEARCH Pitfall 6).` `struct Verify { target: u64, resume: bool, tries: u32, since: Option<Instant> }` and `enum VerifyStep { Done, Wait, Retry(VecDeque<Command>) }`.

    4. Rewrite `begin_restore`: `let resume = s.was_playing && r.resume_allowed;`. When `load`: push SetQueue{play:false}, Seek if position_ms > 0, SetShuffle, SetRepeat, SetVolume, then `if resume { Command::Play } else { Command::Pause }` (Pause always, per D-01/D-04, because MusicKit autoplays after a seek on a fresh load). After `drop(st)`, when load: `self.set(|c| c.player.position_ms = 0)` so a stale pre-crash position cannot pass verification, and set `self.restore.as_mut().unwrap().verify = Some(Verify { target: s.position_ms, resume, tries: 0, since: None })` (clone the needed snapshot values before dropping the borrow). When not load (queue survived re-auth): push Play if `resume && state != Playing`, push Pause if `!resume && state == Playing`; verify stays None.
    5. Add `fn verify_step(&mut self) -> VerifyStep`: return Done if restore or verify is None. Read `self.state_tx.borrow()` player; `landed = pos + SEEK_TOLERANCE_MS >= v.target` (only a lost seek lands short; a playing restore runs ahead legitimately); `state_ok = if v.resume { state == PlayState::Playing } else { state == PlayState::Paused }`. If both, Done. `let since = *v.since.get_or_insert(Instant::now())`; if `since.elapsed() < SEEK_SETTLE` return Wait. If `v.tries >= SEEK_TRIES`: `eprintln!("presto-core: restore: not confirmed after {SEEK_TRIES} tries (at {pos} ms, want {} ms, state {state:?})", v.target)` and return Done. Otherwise `v.tries += 1; v.since = None;` build Retry with Seek{ms: target} if target > 0, then Play or Pause per v.resume. Use direct field access (`self.restore`, `self.state_tx`) so the borrows are disjoint.
