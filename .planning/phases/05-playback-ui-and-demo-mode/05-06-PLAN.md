`edit_queue` (D-08, Pitfall 3) runs on the runtime: read the latest `CoreState`; if `engine != Ready` or `queue.rev != seen_rev` push `Toast::warning("Queue changed. Try again.")` and stop. `queue_ops::apply(&state.queue, &op)`: `Plan::Noop` -> nothing; `Plan::Clear` -> `Command::Pause`; `Plan::Edit(e)` -> `SetQueue { ids: e.ids, start: e.start, play: was_playing }` where was_playing = player.state == Playing; if `e.keep_position && pos >= MIN_SEEK_MS` wait (<= 5 s, via `state().wait_for`) until player.state != Loading and then send `Seek { ms: pos }` (pos = player.position_ms at send time). On success push `Toast::info("Added to Up Next")` for PlayNext and `Toast::info("Added to queue")` for Add.

`open_artist_named`: `data.client().catalog("search", &[("term", &name), ("types", "artists"), ("limit", "1")])`, `parse_search(&name, &v).artists.first()` -> `Event::Open(Page::Artist(item))`; none -> `Toast::warning("Couldn't find that artist.")`.

Do not copy CoreState into events; views read the watch (research anti-pattern). Never block the UI thread on core calls except in `start`/`shutdown`.
