playback.rs:
- `toggle_cmd(state)`: Paused|Stopped|Ended -> Command::Play; Playing|Loading -> Command::Pause
- `next_repeat`: Off -> All -> One -> Off (spotifast RepeatMode::next order)
- `Clock::observe(&mut self, p: &PlayerMirror, now)` re-anchors when (seq, position_ms, state) changes; `position(now)` = anchor + elapsed while Playing, clamped to duration_ms; frozen otherwise. Cases: Playing at 10_000 observed at t0 -> position(t0+1.5s) == 11_500; Paused -> 10_000 at any time; never above duration
- `SeekBar`: `drag(ms)` sets the shown value; `shown(engine_ms, seq, track_id, now)` returns drag value while dragging; `release(now, seq, track_id) -> Option<Command>` returns exactly one `Seek{ms}` and clears drag; after release `shown` returns the target until a newer seq arrives, the track changes, or 1 s passes (SEEK_HOLD), then the engine value. Releasing without a drag returns None
- `seek_by(pos, delta_ms: i64, dur) -> u64` clamps to 0..=dur
- `Volume`: `toggle_mute(current) -> f32`: current > 0 -> remember it, return 0.0; current == 0 -> return remembered or 0.5. `drag(v, now) -> Option<f32>` returns v when nothing sent yet or >= 50 ms since last send, else stores pending; `release() -> Option<f32>` returns the pending value if any
- `volume_by(v, pct) -> f32` adds pct/100, clamps 0..=1
- `fmt_time(ms)`: 0 -> "0:00", 65_000 -> "1:05", 3_725_000 -> "1:02:05"
- `kind_label(&ErrorKind)`: Unavailable "unavailable", Upstream{503} "HTTP 503", Timeout "timeout", Internal "engine error", NotFound "not found", AuthExpired "session expired", RateLimited "rate limited"
- Guard (see action): unplayable current track -> SkipUnavailable once per (id, rev, index); new engine error while not Playing -> SkipFailed with kind label and id marked bad for the session; the same key never yields twice; a later TrackChanged into a bad id skips as SkipUnavailable; consecutive skips reaching queue_len -> AllFailed (single-item failing queue -> AllFailed immediately); Playing with position > 0 on a good track resets the counter; repeat-all queue of 3 unavailable items yields 2 skips then AllFailed, never a loop; `unavailable(id, playable)` = !playable || bad.contains(id)

Guard:
```rust
pub struct GuardInput<'a> {
    pub track: Option<&'a QueueItem>,
    pub state: PlayState,
    pub position_ms: u64,
    pub queue_rev: u64,
    pub queue_index: Option<u32>,
    pub queue_len: usize,
    pub engine_errors: u64,
    pub last_error: Option<&'a ErrorKind>,
}
#[derive(Debug, PartialEq)]
pub enum GuardAction { SkipUnavailable { title: String }, SkipFailed { title: String, kind: String }, AllFailed }
pub struct Guard { bad: HashSet<String>, seen_errors: u64, last_skip: Option<(String, u64, Option<u32>)>, consecutive: usize }
impl Guard {
    pub fn new(engine_errors_now: u64) -> Guard;   // errors before the UI started are ignored
    pub fn observe(&mut self, i: &GuardInput) -> Option<GuardAction>;
    pub fn unavailable(&self, id: &str, playable: bool) -> bool;
}
```
`observe` order: (1) `new_err = engine_errors > seen_errors`, then `seen_errors = engine_errors`; (2) no track -> None; (3) Playing && position > 0 && track playable && not bad -> consecutive = 0, None; (4) `failing = new_err && state != Playing`, if failing insert id into bad; (5) not (`!track.playable || bad.contains(id)`) -> None; (6) key = (id, queue_rev, queue_index), equal to last_skip -> None; (7) last_skip = key, consecutive += 1, if consecutive >= max(queue_len, 1) { consecutive = 0; AllFailed } else if failing { SkipFailed { title, kind: kind_label(last_error or Internal) } } else { SkipUnavailable { title } }. The caller sends Next for both skips and nothing for AllFailed (D-12 "playback stops").
