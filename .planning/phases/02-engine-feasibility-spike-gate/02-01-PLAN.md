Only after Task 1 returned "proceed".

1. Find the newest stable wvcus tag (D-02):
   `git ls-remote --tags https://github.com/castlabs/electron-releases | grep -o 'v[0-9]*\.[0-9]*\.[0-9]*+wvcus$' | sort -V | tail -5`
   Pick the highest tag with no `-alpha`/`-beta` in the 43 to 45 series. Research found `v44.5.1+wvcus` (2026-10-07). Use `v44.1.0+wvcus` only if the newest one fails to install.

2. Create `engine/package.json` by hand (no `npm init`):
```json
{
  "name": "presto-engine",
  "version": "0.1.0",
  "private": true,
  "description": "Presto engine: castlabs Electron hosting music.apple.com, speaking presto-ipc over a Unix socket",
  "main": "main.js",
  "license": "UNLICENSED",
  "scripts": {
    "start": "electron .",
    "test": "node --test test/"
  },
  "devDependencies": {}
}
```
3. From `engine/`: `npm install --save-dev --save-exact "github:castlabs/electron-releases#<TAG>"`. It downloads the ECS binary (hundreds of MB). Confirm `devDependencies.electron` is `github:castlabs/electron-releases#<TAG>` (exact tag, not a branch).

4. Append to `.gitignore`:
```
/engine/node_modules
```
Do not ignore `.planning/**/logs`: logs are committed after a secrets grep (later plans).

5. Record versions: `node -p "require('./engine/node_modules/electron/package.json').version"` and `ls engine/node_modules/electron/dist/` (look for `electron`, `chrome-sandbox`). Check `stat -c '%U %a' engine/node_modules/electron/dist/chrome-sandbox`. Note in the SUMMARY whether it is root-owned 4755 (it will not be from npm). `/proc/sys/kernel/unprivileged_userns_clone` is 1 on this machine, so Chromium should use the namespace sandbox; `--no-sandbox` is a fallback only if the engine refuses to start in plan 02-04 (Pitfall 10).

Do not run electron here: no display is needed yet and nothing may load Apple pages in this plan.
