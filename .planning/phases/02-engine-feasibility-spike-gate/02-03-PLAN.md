`engine/bridge.js` is a single plain-JS file (no bundler, no imports) that works both as a Node module for tests and as a script injected via `executeJavaScript`:
```js
(function () {
  'use strict';
  // ... functions below ...
  if (typeof module === 'object' && module.exports) {
    module.exports = { createBridge, mapState, mapItem, mapApiError, install };
  } else {
    install(window);
  }
})();
```
Functions:
- `mapState(MusicKit, n)`: reverse-lookup the name in `MusicKit.PlaybackStates` (read the enum at runtime, Pattern 2). playing->"playing"; paused->"paused"; ended|completed->"ended"; none|stopped->"stopped"; everything else (loading, seeking, waiting, stalled, unknown) -> "loading".
- `mapItem(mi)`: `id: String(mi.id)`, `title: a.name ?? mi.title ?? ""`, `artist: a.artistName ?? ""`, `album: a.albumName ?? ""`, `duration_ms: Math.round(a.durationInMillis ?? (mi.playbackDuration ?? 0))`, `artwork_url: a.artwork?.url ? url.replace("{w}","600").replace("{h}","600") : null`, `playable: mi.isPlayable !== false`, where `a = mi.attributes ?? {}`. `mapItem(null)` returns null.
- `mapApiError(e)`: `status = e?.status ?? e?.response?.status ?? e?.httpStatusCode`; 401/403 -> `{code:"auth_expired"}`; 429 -> `{code:"rate_limited", retry_after_ms:null}`; 404 -> `{code:"not_found"}`; other integer -> `{code:"upstream", status}`; none -> `{code:"internal"}`. Returns `{kind, message: String(e?.message ?? e).slice(0, 200)}`. Never copies headers or the response object.
- `createBridge({MusicKit, mk, presto, setInterval})` returns `{handle(frame), start(), diag()}`; keeps `seq` and `rev` counters.
  - `handle`: for `t:"cmd"`, run the command in try/catch, bump seq for play/pause/seek/next/prev/set_queue, `presto.reply(id, {status:"ok", data:null})`; errors -> `presto.reply(id, {status:"err", error: mapApiError(e)})` but with kind internal unless a status is present. Command map: play->`mk.play()`, pause->`mk.pause()`, seek->`await mk.seekToTime(ms/1000)`, next->`await mk.skipToNextItem()`, prev->`await mk.skipToPreviousItem()`, set_volume->`mk.volume = volume`, set_shuffle->`mk.shuffleMode = on ? (MusicKit.PlayerShuffleMode?.songs ?? 1) : (MusicKit.PlayerShuffleMode?.off ?? 0)`, set_repeat->`mk.repeatMode = MusicKit.PlayerRepeatMode?.[mode === "off" ? "none" : mode] ?? {off:0,one:1,all:2}[mode]`, set_queue->`await mk.setQueue({songs: ids, startPlaying: true}); if (start > 0) await mk.changeToMediaAtIndex(start)`. Unknown type -> err internal "unknown command <type>".
  - For `t:"req"`: method other than "get" -> err internal "spike engine supports GET only". Else `const res = await mk.api.music(req.path, req.query ?? {})`; `const data = res?.data ?? res`; `const json = JSON.stringify(data)`; if `json.length > 4_000_000` -> err internal "response too large; lower limit" (MAX_LINE, Pitfall 9); else reply ok `{data: JSON.parse(json)}` (plain clone so it crosses contextBridge). Errors -> `mapApiError`.
  - `start()`: emit `auth` from `mk.isAuthorized`; `addEventListener` for `playbackStateDidChange` (emit playback_state from `e?.state ?? mk.playbackState`, plus a progress), `mediaItemDidChange` and `nowPlayingItemDidChange` (track_changed with `mapItem(mk.nowPlayingItem)`), `queueItemsDidChange` and `queuePositionDidChange` (rev++, queue_changed `{rev, items: (mk.queue?.items ?? []).map(mapItem), index: pos >= 0 ? pos : null}`), `playbackVolumeDidChange` (volume), `authorizationStatusDidChange` (auth signed_in/signed_out from `mk.isAuthorized`). `setInterval(500)` emits progress only while `mk.isPlaying` with `position_ms: Math.round(mk.currentPlaybackTime*1000)`, `duration_ms: Math.round(mk.currentPlaybackDuration*1000)`.
  - `diag()`: plain object `{bridge: 1, musickit_version: MusicKit.version ?? null, build: <src of first script whose src contains "musickit" or "index", query string stripped>, playback_states: MusicKit.PlaybackStates, mk_members: Object.getOwnPropertyNames(Object.getPrototypeOf(mk)), queue_members: Object.getOwnPropertyNames(Object.getPrototypeOf(mk.queue ?? {})), api_music_arity: mk.api?.music?.length ?? null, has_media_session: typeof navigator !== "undefined" && "mediaSession" in navigator, ua: navigator?.userAgent ?? null}`. `engine/preload.js` (sandboxed preload, only `contextBridge` and `ipcRenderer`):
```js
const { contextBridge, ipcRenderer } = require('electron');
let handler = null;
ipcRenderer.on('presto:in', (_e, frame) => { if (handler) handler(frame); });
contextBridge.exposeInMainWorld('__presto', {
  ready: (diag) => ipcRenderer.send('presto:ready', diag),
  emit: (evt) => ipcRenderer.send('presto:out', { t: 'evt', evt }),
  reply: (id, outcome) => ipcRenderer.send('presto:out', { t: 'res', id, outcome }),
  onFrame: (cb) => { handler = cb; },
});
```
