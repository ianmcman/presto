`src/session.rs`:
```rust
pub struct EngineOpts { pub bin: PathBuf, pub app_path: Option<PathBuf>, pub socket: PathBuf, pub profile: PathBuf, pub extra: Vec<String>, pub log_dir: PathBuf, pub label: String }
pub struct Session {
    conn: Conn, pub child: tokio::process::Child, pub engine_hello: Hello,
    events: std::fs::File,                       // <log-dir>/events-<label>-<ts>.ndjson, one received frame per line, Pong frames skipped
    next_id: u64, ping_seq: u64, unanswered: u32,
    pub counts: BTreeMap<&'static str, u32>,     // per evt type: "playback_state","progress","track_changed","queue_changed","volume","auth","error"
    pub states: Vec<PlayState>, pub last_auth: Option<AuthState>, pub last_progress: Option<(u64, u64)>, // (position_ms, duration_ms)
}
impl Session {
    pub async fn start(o: &EngineOpts) -> R<Session>;
    pub async fn wait_for<T>(&mut self, within: Duration, mut f: impl FnMut(&Frame) -> Option<T>) -> R<T>;
    pub async fn call(&mut self, cmd: Command) -> R<Outcome>;
    pub async fn get(&mut self, path: &str, query: &[(&str, &str)]) -> R<Outcome>;
    pub async fn shutdown(self) -> R<std::process::ExitStatus>;
    pub fn pid(&self) -> Option<u32>;
}
```
- `start`: `transport::bind(&o.socket)`; spawn `tokio::process::Command::new(&o.bin)` with args `[app_path?] --socket <socket> --profile <profile> <extra...>`, stdout and stderr both to `<log-dir>/engine-<label>-<ts>.log` (`File::create` then `try_clone` for the second), `kill_on_drop(true)`, env inherited (display vars come from the caller). Accept with a 30 s timeout (Electron startup is slower than the mock); then recv the engine `Frame::Hello` within `Kind::Hello.timeout()`, `check(PROTO)` (major mismatch is an error naming both versions), send `Frame::Hello(Hello::new(Role::Presto, &[], Some(format!("presto-spike {}", env!("CARGO_PKG_VERSION")))))`.
- `wait_for`: loop with `tokio::select!` over `transport::recv` and a `tokio::time::interval(HEARTBEAT_INTERVAL)` ticker, bounded by `tokio::time::timeout(within, ..)`. On tick: if `unanswered >= HEARTBEAT_MISSES` return Err("engine hung: 3 pings unanswered"); else send `Frame::Ping{seq}` and `unanswered += 1`. On `Pong{seq}` matching the latest: `unanswered = 0`. Every received non-Pong frame: write `serde_json::to_string` + `\n` to the events file, update `counts`/`states`/`last_auth`/`last_progress` for `Evt`, then return `Some(t)` from `f` if it matches. EOF: Err("engine closed the connection"). Timeout: Err("timed out after {within:?} waiting for <caller label>") (add a `what: &str` param if helpful).
- `call`: id = next_id++; send `Frame::Cmd{id,cmd}`; `wait_for(frame.kind().unwrap().timeout(), |f| matches Res{id: rid, outcome} if rid == id => Some(outcome.clone()))`. `get`: same with `Frame::Req{id, req: ApiRequest::get(path) + query}`.
- `shutdown`: drop the conn (the engine quits on EOF so Chromium flushes cookies, Pitfall 5), wait up to 10 s for `child.wait()`, else `child.kill()` and return its status. Never SIGKILL first.
