`src/player.rs`:
```rust
pub struct Player { queue: Vec<QueueItem>, rev: u64, index: Option<usize>, state: PlayState, base_ms: u64, base_at: Instant, volume: f32, shuffle: bool, repeat: RepeatMode, seq: u64 }
impl Player {
    pub fn new(now: Instant) -> Self;   // empty queue, rev 0, Stopped, volume 1.0, repeat Off, seq 0
    pub fn position(&self, now: Instant) -> u64;  // Playing: min(base_ms + elapsed since base_at, duration); else base_ms
    pub fn apply(&mut self, cmd: &Command, now: Instant) -> Result<Vec<Event>, IpcError>;
    pub fn tick(&mut self, now: Instant) -> Vec<Event>;
}
```
Position is always computed from `(base_ms, base_at)`, never incremented (Pitfall 6). Rules:
- `set_queue{ids,start}`: resolve every id via `catalog::song` (unknown -> NotFound naming the id; empty ids or `start >= len` -> Internal); replace queue, `rev += 1`, index = start, base 0, Playing, `seq += 1`; events `queue_changed`, `track_changed`, `playback_state playing`, `progress`.
- `play`: empty queue -> Unavailable "queue is empty"; if Ended, restart current index at 0; Playing, rebase at current position, `seq += 1`; events `playback_state`, `progress`.
- `pause`: freeze position into base_ms, Paused, `seq += 1`; events `playback_state`, `progress`.
- `seek{ms}`: empty -> Unavailable; base_ms = min(ms, duration), base_at = now, `seq += 1`; event `progress`.
- `next`: empty -> Unavailable; if last and repeat Off -> Ended, base_ms = duration, `seq += 1`, event `playback_state ended`; otherwise move to index+1 (wrap to 0 on repeat All).
- `prev`: empty -> Unavailable; position > 3000 or index 0 -> restart current at 0 (`seq += 1`, event `progress`); else move to index-1.
- Moving to another index (next/prev/natural advance): `rev += 1`, base 0, `seq += 1`, keep Playing/Paused state; events `queue_changed`, `track_changed`, `progress`.
- `set_volume` clamps to 0.0..=1.0 -> `volume`; `set_shuffle` stores the flag -> `shuffle`; `set_repeat` -> `repeat`. Add `// ponytail: shuffle does not reorder the mock queue; reorder if a UI test needs it`.
- `tick`: if Playing and position >= duration: repeat One -> restart same index at 0 (`seq += 1`, `progress`); else advance as `next` would. Else if Playing -> `progress` with current seq. Otherwise no events.

Flow:
1. `transport::connect(&args.socket)`; on error `eprintln!` and exit 1.
2. Send `Frame::Hello(Hello::new(Role::Engine, &[caps::PLAYBACK, caps::QUEUE, caps::API, caps::MOCK], Some(format!("presto-engine-mock {}", env!("CARGO_PKG_VERSION")))))`.
3. Await the first frame with `tokio::time::timeout(Kind::Hello.timeout(), transport::recv(..))`. Not a Hello, timeout, or EOF -> `eprintln!` and exit 2. `hello.check(PROTO)` Err -> `eprintln!("{err}")` and exit 2 (D-04).
4. Send `Evt { evt: Event::Auth { state: AuthState::SignedIn } }`.
5. Loop with `tokio::select!` over `transport::recv(&mut conn)` (cancel-safe) and a `tokio::time::interval(Duration::from_millis(500))` tick (`MissedTickBehavior::Skip`). Dispatch through a pure function so plan 01-04 can extend it:
```rust
struct Engine { player: Player }
impl Engine { fn handle(&mut self, frame: Frame, now: Instant) -> Vec<Frame>; fn tick(&mut self, now: Instant) -> Vec<Frame>; }
```
   - `Ping{seq}` -> `[Pong{seq}]`
   - `Cmd{id, cmd}` -> `player.apply`; Ok(events) -> events as `Evt` frames followed by `Res{id, Outcome::Ok{data: Value::Null}}`; Err(e) -> `[Res{id, Outcome::Err{error: e}}]`. Events always precede the `res`.
   - `Req{id, req}` -> `[Res{id, catalog::handle(&req)}]`
   - `Mock{id, ..}` -> `[Res{id, Err Internal "fault injection not implemented"}]` (plan 01-04 replaces this)
   - `Hello`, `Res`, `Evt`, `Pong` from presto -> `eprintln!` and ignore
   - tick -> `player.tick(now)` events as `Evt` frames
