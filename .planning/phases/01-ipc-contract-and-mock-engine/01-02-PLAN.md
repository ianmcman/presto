Write `docs/PROTOCOL.md` by hand (D-14). Sections, in order:
1. `## Overview`: two processes, presto listens and the engine connects (D-01, D-02); engine is replaceable; Rust never holds Apple credentials and the engine adds auth inside the page (D-08).
2. `## Transport`: Unix domain socket at `$XDG_RUNTIME_DIR/presto/engine.sock`, parent dir mode 0700, socket 0600, stale socket removed on bind; NDJSON, one JSON object per `\n`-terminated UTF-8 line, max line 4 MiB (engines paginate); engine launch contract: argv `--socket <path> --profile <dir>` or env `PRESTO_SOCKET` / `PRESTO_PROFILE`, argv wins; presto spawns the engine as a child and terminates it on exit (D-02); engine logs go to stderr/stdout, which presto captures to a log file under its state dir and tails on failure (D-03); never log API response bodies at info level.
3. `## Handshake and versioning`: engine sends `hello` first, presto replies with its `hello`; protocol version `1.0`; minor mismatch tolerated, features gated by capabilities; major mismatch is a hard error with a message naming both versions, and the side detecting it closes the connection (the mock exits with code 2); capability table: `playback`, `queue`, `api`, `mock` (presto never sends `mock` frames unless the engine hello lists `mock`; real engines never list it).
4. `## Frames`: table of `t` values `hello`, `cmd`, `req`, `res`, `evt`, `ping`, `pong`, `mock` with direction and fields (`id`, `seq`, `cmd`, `req`, `outcome`, `evt`, `fault`, `proto`, `major`, `minor`, `role`, `presto`, `engine`, `capabilities`). One full JSON example per frame type.
5. `## Commands`: tag `type`; each of `play`, `pause`, `seek` (`ms`), `next`, `prev`, `set_volume` (`volume` 0.0 to 1.0), `set_shuffle` (`on`), `set_repeat` (`mode`: `off`, `one`, `all`), `set_queue` (`ids`, `start`). Rule: every `cmd` gets exactly one `res` with the same `id`; events caused by a command are sent before its `res`.
6. `## API requests`: `req` fields `method` (`get`, `post`, `put`, `patch`, `delete`), `path`, `query`, `body`; there is deliberately no headers field. `outcome` tag `status`: `ok` (`data`) or `err` (`error`).
7. `## Errors`: `error` = `kind` + `message`; `kind` tag `code`: `timeout`, `auth_expired`, `rate_limited` (`retry_after_ms`), `not_found`, `unavailable`, `upstream` (`status`), `internal`, each with when it is used; the closed set maps to UI states (D-09). `timeout` is synthesized by the requester.
8. `## Events`: tag `type`: `playback_state` (`state`: `stopped`, `loading`, `playing`, `paused`, `ended`; `seq`), `progress` (`position_ms`, `duration_ms`, `seq`; about every 500 ms while playing plus on every state change; receivers interpolate), `track_changed` (`item`), `queue_changed` (`rev`, `items`, `index`; full snapshot, `rev` bumps on every queue or index change including natural advance; receivers drop `rev` lower than the last applied, D-07), `volume`, `shuffle`, `repeat`, `auth` (`state`: `signed_out`, `signing_in`, `signed_in`, `expired`), `error`. `seq` semantics: bumps on each user-initiated change; drop progress with older `seq`. `QueueItem` fields `id`, `title`, `artist`, `album`, `duration_ms`, `artwork_url`, `playable`.
9. `## Timeouts and heartbeat`: table copied from `Kind::timeout` (hello 5 s, command 5 s, set_queue 15 s, GET request 20 s, write request 30 s, mock control 5 s); enforced by the requester, never on the wire; presto sends `ping` every 2 s, engine answers `pong` with the same `seq`; 3 unanswered pings (6 s) means hung. Pongs must never wait behind slow request handling.
10. `## Mock engine control`: `mock` frame with `fault` (tag `kind`): `none`, `hang`, `crash` (`after_ms`), `auth_expired`, `slow` (`delay_ms`); CLI `--fault` repeatable with syntax `none|hang|crash|crash@<ms>|auth_expired|slow|slow=<ms>` (slow default 3000 ms); startup faults take effect right after the handshake. Semantics (D-12): `hang` drops every outbound frame (replies, events, pongs) while still reading, socket stays open, and only a `mock` `none` frame clears it; `crash` exits with status 101 immediately or after `after_ms`; `auth_expired` emits `auth` `expired` and every `cmd`/`req` then gets `err` `auth_expired` until cleared (`none` then emits `auth` `signed_in`); `slow` delays every `res` by `delay_ms` while `evt` and `pong` stay on time. `mock` frames are acked with `res` immediately and are never delayed.
11. `## Security`: no IPC type may carry an Apple credential field; enforced by `crates/presto-ipc/tests/schema.rs` (allowlist `auth`, `auth_expired`).

Every wire name must appear in backticks somewhere in the doc. Run the test and add any name it reports missing.
