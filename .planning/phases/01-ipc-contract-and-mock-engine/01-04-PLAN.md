`src/fault.rs`:
```rust
#[derive(Default)]
pub struct Faults { pub hang: bool, pub auth_expired: bool, pub slow: Option<Duration> }
impl Faults {
    /// Applies one fault. Returns events to emit. Crash is handled by the caller (process exit).
    pub fn apply(&mut self, spec: &FaultSpec) -> Vec<Event>;
}
```
- `None`: clear hang, slow and auth_expired; if auth_expired was set, return `[Auth{SignedIn}]`.
- `Hang`: `hang = true`. `AuthExpired`: set flag, return `[Auth{Expired}]`. `Slow{delay_ms}`: `slow = Some(Duration::from_millis(delay_ms))`. Faults stack (slow + auth_expired can both be active).
- `Crash{..}` is not handled here.

`src/main.rs` changes (D-11, D-12, Research Pattern 5 and Pitfall 5):
1. Args: add `#[arg(long = "fault", value_parser = clap::value_parser!(FaultSpec))] faults: Vec<FaultSpec>` (repeatable; `FaultSpec: FromStr` gives a clap value parser; if that macro form does not compile use `value_parser = |s: &str| s.parse::<FaultSpec>()`).
2. `Engine` gains `faults: Faults`. Add `fn crash(spec)`: `Crash{after_ms: None}` -> `eprintln!("mock: crash fault"); std::process::exit(101)`; `Crash{after_ms: Some(ms)}` -> `tokio::spawn(async move { sleep(ms).await; eprintln!(..); std::process::exit(101) })`.
3. Startup faults take effect right after the handshake: the post-handshake auth event is `auth expired` instead of `auth signed_in` if any startup fault is `auth_expired`; apply every startup spec in order (crash via `crash()`).
4. `handle` changes:
   - `Mock{id, fault}`: crash -> `crash(fault)` (a `Crash{after_ms: Some}` first returns its ack); otherwise `faults.apply`; return the resulting `Evt` frames then `Res{id, Ok{data: null}}`. Mock acks are never delayed by slow.
   - While `auth_expired`: every `Cmd` and `Req` returns `[Res{id, Err{IpcError::new(ErrorKind::AuthExpired, "mock: session expired")}}]` without touching the player or catalog. `Ping` still gets `Pong`.
5. Outbound gating in the loop, not in `handle`:
   - Hang: before sending any frame, if `engine.faults.hang` is true, drop it. Exception: frames returned by `handle` for an inbound `Mock` frame (its events and ack) are always sent, so both the `hang` ack and the `none` ack reach the test. Inbound reading continues so the socket stays open and a `mock none` frame can clear the hang.
   - Slow: when `faults.slow` is `Some(d)`, every `Res` frame that is not a `Mock` ack goes through `tokio::spawn(async move { sleep(d).await; let _ = tx.send(frame); })` on a `tokio::sync::mpsc::unbounded_channel::<Frame>()`. Add a third `select!` arm `Some(f) = rx.recv()` that sends `f` (subject to hang gating). `Evt` and `Pong` frames are sent immediately, so slow stays distinguishable from hang (Pitfall 5).
   - Never `sleep` inline in the select loop.
